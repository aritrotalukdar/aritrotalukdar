### 📈 Real-Time Stock Predictive Analytics Dashboard
A live market-data pipeline serving **7-day BUY / HOLD / SELL signals across 500+ instruments**, replacing manual chart analysis for retail investors.
- Trained a **3-layer LSTM** on 12 risk indicators (RSI, MACD, Bollinger Bands), reaching **~1% MAPE** on 7-day forecasts with rolling-window validation to eliminate lookahead bias
- Deployed the full stack via **Docker Compose**, separating the ML backend from the Streamlit frontend for one-command deployment and independent scaling
`FastAPI` · `LSTM` · `Streamlit` · `Docker`
